# 📊 HR Attrition Dashboard - Power BI

This Power BI dashboard provides a visual analysis of employee attrition trends within the organization.. It helps stakeholders ubderstand key factors that influence employee turnover such as work experience, satisfaction, gender, and commute distance.


## 📌 Key Metrics & Visuals

### 👥 Total Employees
- **1470 employees** in the dataset.

### 📉 Attrition Rate
- Overall **attrition rate: 16.12%**
- Visualized using a KPI Card.


## 📊 Visual Components

### 1. Attrition by Working Years
- Bar chart categorizing employees based on total years worked:
  - `0–10 years`
  - `11–20 years`
  - `21–30 years`
  - `31+ years`
- Highest attrition observed in the **0–10 years** range.

### 2. Attrition by Employee Satisfaction
- Bar chart of attrition counts by satisfaction level:
  - `Very Satisfied`
  - `Satisfied`
  - `Dissatisfied`
  - `Very Dissatisfied`

### 3. Attrition by Distance to Work
- Donut chart split into:
  - **Near By**
  - **Far**
  - **Very Far**
- Indicates how distance from work influences turnover.

### 4. Attrition by Department
- Donut charts displaying attrition by department:
  - HR
  - R&D
  - Sales
- Sales department has the highest attrition count (**92**).

  ### 5. Gender-wise Attrition
- KPI cards for:
  - **Female Attrition**: 87 employees
  - **Male Attrition**: 150 employees
- Donut chart shows **female attrition share**: 36.71%
- Male-female attrition ratio shown as **0.63**
